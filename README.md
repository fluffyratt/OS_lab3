## Запуск програми

Для компіляції та запуску лабораторної роботи необхідно відкрити термінал у каталозі `cache_lab`.

Команди:

```bash
make
make quick
make run
```

- `make` — компіляція програми мовою C.
- `make quick` — короткий тестовий запуск для перевірки роботи програми.
- `make run` — повний запуск усіх експериментів із п’ятьма повтореннями кожної конфігурації.

Після виконання програми результати зберігаються у файлах `results/raw.csv` та `results/summary_median.csv`. Побудовані графіки знаходяться в папці `plots/`.

## Результати дослідження

Експерименти виконано в середовищі Ubuntu/Linux через WSL із використанням компілятора GCC.

У роботі досліджено вплив розміру даних, способу доступу до пам’яті, множення матриць, false sharing та синхронізації потоків на продуктивність програми.

Для кожної конфігурації виконано п’ять вимірювань. Для порівняння результатів використано медіанні значення. За отриманими даними побудовано шість графіків.
